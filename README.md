# 实习经历精校材料

个人私有备份。请保持 **Private**。

密码、验证码图、token、证据截图、接口响应原文、打测试环境的探针脚本不入库。用例 JSON、执行手册、缺陷反馈、周报、规则和 pytest 框架在。

## 回学校改简历的顺序

1. `实习经历/00-待你确认.md`
2. `实习经历/软件测试.md` 或 `测试开发.md` 的「精简」段
3. 字数不够再从「完整稿」往上加，数字只准对 `事实底稿.md`
4. 面试用 `面试口述.md`，项目细节翻 `用例归档/` 和 `缺陷反馈/`

## 目录

| 路径 | 用途 |
|---|---|
| `实习经历/` | 两份正文、自我评价、口述、事实底稿 |
| `工作记录/` | 周报、提效指南 |
| `项目说明/` | 两个产品是干什么的 |
| `项目规则/` | 脱敏后的 AGENTS / 交接 / 评审要点 |
| `用例源JSON/` | 工作区 cases_*.json |
| `用例归档/` | 执行过程、禅道 CSV、证据清单（无截图） |
| `缺陷反馈/` | 已写的 bug / 非缺陷说明 |
| `接口自动化/` | pytest + requests |
| `接口报告/` | 12 接口 / 89 条那次摸底 |
