# 实习经历精校材料（脱敏）

个人私有备份，用来回学校改简历，**不要改成 Public**。

本仓库不是公司代码全集。密码、验证码、token、证据截图、完整用例归档、针对测试环境的探针脚本都没有放进来。

## 怎么用

1. 先看 `实习经历/00-待你确认.md`，把公司全称和入职月份填对。
2. 用 `实习经历/事实底稿.md` 核对数字，再改 `软件测试.md` / `测试开发.md`。
3. 写不下去时去翻 `工作记录/`，不要凭记忆加条数。
4. `接口自动化/` 是你自己搭的 pytest 框架，面试讲测开时对着这里说。

## 目录

| 路径 | 用途 |
|---|---|
| `实习经历/` | 两份简历正文 + 事实底稿 + 裁剪说明 |
| `工作记录/` | 周报、提效指南（写经历时的依据） |
| `项目说明/` | 两个项目是干什么的（已去掉账号密码） |
| `接口自动化/` | pytest + requests，CDP 复用登录态 |

## 刻意没放的

- 账号密码、短信/图形验证码流程里的凭据
- `D:\测试用例` 下的截图、接口报文、四件套原件
- 工作区 `.codex-build` 里打测试环境的探针
- 系统级测试规则全文（那是给模型用的，不是简历素材）
