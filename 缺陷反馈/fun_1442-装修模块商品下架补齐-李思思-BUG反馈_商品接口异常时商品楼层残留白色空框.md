# BUG 反馈：商品接口异常时，PC 首页商品楼层组件残留白色空占位框并报 Network Error

## 基本信息

- **所属产品**：华硕新商城（PC 端商城）
- **所属模块**：装修模块-商品楼层组件（fun_1442 装修模块商品下架补齐）
- **需求背景**：装修中商品组件不应出现白色占位框/白底图（未上架商品不显示、后续商品自动补齐）
- **测试环境**：dev 测试环境（https://dev-mall-pc.njsyue.com/store/）
- **发现人**：王文东
- **发现日期**：2026-08-13
- **缺陷类型**：性能问题（接口超时/失败场景下的兜底表现）
- **严重程度 / 优先级**：中（P2）
- **状态**：新建

## 缺陷描述

当商品数据接口（`/v3/goods/front/goods/productList`）请求失败/超时/被拦截时，PC 首页**商品楼层组件残留 8 个白色空商品占位框**（无任何商品内容），且控制台出现 `Error: Network Error` 报错。页面框架未崩溃，但"白色空框"场景与需求背景"避免白框展示"不符，接口异常兜底不完善。

## 复现步骤

前置：PC 商城首页商品楼层组件配置 8 个商品且全部上架。

1. 打开 Chrome，访问 `https://dev-mall-pc.njsyue.com/store/`。
2. 按 F12 打开开发者工具 → 切到 Network（网络）标签。
3. F5 刷新页面，在 Network 列表中找到 `/v3/goods/front/goods/productList` 请求。
4. 右键该请求 → 点「Block request URL」（屏蔽请求 URL）→ 确认 Block。
5. 再次 F5 刷新页面，等待页面加载完成（约 3~5 秒）。
6. 向下滚动到商品楼层组件区域（8 个商品格子位置）。
7. 切到 Console（控制台）标签查看报错。

## 预期结果

商品接口异常时：
- 页面**无白框、无 JS 报错**；
- 商品楼层组件按空态或兜底处理：整体隐藏组件，或显示"加载失败/暂无数据"提示；
- 不残留白色空商品占位框。

## 实际结果

- 页面框架、导航、广告横幅正常渲染（页面不崩溃）；
- **商品楼层组件残留 8 个白色空商品占位框**（骨架/占位容器渲染出来，但无任何商品内容）；
- 控制台出现 `Failed to load resource: net::ERR_FAILED` 和 `Error: Network Error` 报错。

## 影响范围

- PC 首页商品楼层组件；同理可能影响 H5/小程序/App 端所有商品组件（推荐商品、商品分组等）；
- 接口异常场景（后端超时/报错、弱网、接口被拦截）下，用户会看到白色空框，体验差且与"避免白框"需求不符。

## 建议处理方案

商品组件接口加载失败时：
1. 清除/隐藏已渲染的商品卡片骨架（空占位框）；
2. 整体隐藏组件或展示"加载失败/暂无数据"空态提示；
3. 补全错误处理，避免未捕获的 `Network Error` 抛到控制台。
