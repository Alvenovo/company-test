## 接口自动化（测开版依据）

- 目录：本仓库 `接口自动化/`
- 栈：pytest、requests、websocket-client、Chrome CDP 读 localStorage token
- 现行用例：smoke（登录后列表 + 无 token 应失败）+ 商品日志按 spu 搜索（parametrize）
- 更早一次接口覆盖：12 个列表/详情类接口、89 条（正向 / 无 token / 越权 / 边界）。那是历史执行，不要说成「长期维护的 89 条自动化套件」
- 明确没有：Allure 报告、Jenkins、Page Object、小程序 automator（本机无源码）
