# 自我评价（两岗各留 3～4 行）

## 软件测试

本科计算机，实习做电商多端功能测试。习惯按成功标准写可判定用例，执行留接口和截图证据，不把「看起来对」当通过。能独立走完设计、评审回改、五端执行、缺陷复现到回归。熟悉 HTTP 抓包和基本 SQL。可立刻上手功能测试，接口自动化能写 pytest 冒烟。

## 测试开发

本科计算机，实习把测试交付做成可重复流程，并用 pytest + requests 对真实后台接口做分层自动化。鉴权复用已登录态，环境不够 skip 而不是误报。能把偶现缺陷做成对照实验和量化回归。业务测试也做过，不是只会搭架子。后续计划补报告和 CI，不假装已经有。

## 不要用的空话

沟通能力强、认真负责、抗压、热爱测试、快速学习（除非你能举出本仓库里的例子）。
