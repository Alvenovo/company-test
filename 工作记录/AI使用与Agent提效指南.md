# AI 使用与 Agent 提效指南（精校摘录）

- 日期：2026-08-14
- 作者：王文东
- 用途：回学校写实习经历时对照「我到底做了什么工程化」，不要当简历正文粘贴

## 1. 实际做过的场景

| 场景 | 内容 |
|---|---|
| 用例编写与整改 | 单周 4 个需求约 92 条；组长评审后按批注改正并同步交付物 |
| bug 复现 | 店铺空白竞态 20+ 轮、接口时序、强制延迟对照；资源 404 与白框 |
| 数据核验 | 48 条活动扫描、图片 URL HTTP 状态 |
| 测试执行 | 后台上下架自动化 + 五端人工核对 |
| 交付物 | 禅道 12 列 CSV、查看版、状态清单、执行手册一次生成并校验 |
| 环境 | 多端登录复用、验证码人工确认、多角色会话隔离 |

## 2. 量化（面试可讲过程，简历不要堆「省了几小时」）

- 竞态：手动 20–30 轮约 1–2 小时 → 脚本几分钟，能记下接口顺序
- 回归：30 轮统计通过率，不抽几下凭感觉

## 3. 工程化机制（测开版第二条的依据）

1. 项目规则写进 AGENTS.md，换对话不丢约定
2. 会话交接记录进度 / 环境 / 待办
3. 用例源 JSON 唯一数据源，改一处全套再生
4. 登录态复用，不在代码里写密码
5. 测试数据登记台账
6. 证据按用例归档，一个证据要能区分通过失败

## 4. 红线（体现质量意识，不要写成「我用了 ChatGPT」）

- 未验证不写已验证
- 测试环境写操作先说明再做
- 小程序无源码就标受阻，不假装自动化已通
