## 0. 环境与账号准备（必读）

### 华硕小二后台
- 地址：https://dev-asus.njsyue.com/sxr/web/index.html#/staff-admin（自动跳转登录页）
- 账号：测试账号，密码：本机凭据，不入库
- 登录流程：填入账号密码 → 页面显示图形验证码（createCaptcha 接口生成）→ 输入验证码 → 点击「登 录」。验证码需向**王文东**索取；验证码过期/错误时点击验证码图片刷新后重填。
- 需求模块：登录后 → 左侧「兑换活动管理」→「活动兑奖」（列表 URL：#/exchangeActivity；创建：#/exchangeActivityAdd；编辑：#/exchangeActivityEdit?prizeActivityId=xxx）。

### 需求说明
- 本次需求：**活动兑奖创建活动时，活动类型下拉新增「微信小店」选项**（后端 type=12）。
- 回归重点（本次新发现缺陷）：编辑活动时「所属店铺」首次进入可能空白（detail 与 storeList 接口竞态）；部分活动「邮件截图」不显示（OSS 地址双编码导致 404）。
- 通用判断标准：
  - 「所属店铺回显正常」= 编辑页所属店铺输入框显示完整店铺名（如 华硕商城/华硕商城），非空白；
  - 「邮件截图正常」= 编辑页出现图片缩略图且可正常加载，无裂图/空白/异常占位；
  - 复现竞态可多次进入编辑页观察（首次进入更容易触发），或用抓包工具观察 `cms/prize/detail` 与 `cms/common/storeList` 谁先返回。

### TC_活动兑奖_001（P1）活动创建页活动类型下拉新增「微信小店」选项

- **执行步骤**
  1. 打开活动类型下拉选择框，遍历全部选项。
  2. 核对「微信小店」选项存在及可选中。
  3. 抓取活动类型字典接口（prizeActivityTypeList）核对微信小店标识。

  1. 下拉列表内新增「微信小店」选项，原有活动类型完整保留。
  2. 「微信小店」选项可正常选中。
  3. 接口返回 activityType=12、activityTypeName=微信小店，与页面一致。
- **本次实测状态**：已实测通过。2026-08-12 实跑：活动类型下拉含「微信小店」（type=12），原有 11 个类型完整保留，与接口字典一致。对应禅道用例 3249。

## 二、回归用例（4 条，2026-08-12 新发现缺陷）

> 三个审核状态共用同一缺陷根因（前端竞态），分别建用例便于回归统计。

### TC_活动兑奖回归_001（P1）编辑审核通过活动首次进入所属店铺回显校验
- **前置**：存在审核通过的活动（如 wmw抽奖实物20250925002，ID 147）。
- **数据准备**：使用审核通过活动 wmw抽奖实物20250925002（编码 0N31，ID 147，所属店铺 华硕商城/华硕商城）。
- **执行步骤**
  1. 从活动列表首次点击审核通过活动【编辑】。
  2. 核对所属店铺字段是否显示（如 华硕商城/华硕商城）。
  3. 返回列表再次点击【编辑】，再次核对所属店铺。
  4. 抓取 prize/detail 与 common/storeList 接口响应及返回顺序。
- **预期结果**
  1. 首次进入编辑页所属店铺应正常回显，不出现空白。
  2. detail 接口正确返回 storeId/platformId/平台店铺名（如 storeId=33、华硕商城-华硕商城）。
  3. 多次进入显示一致；detail 先于 storeList 返回时也应正常回显。
- **本次实测状态**：疑似缺陷。2026-08-12 复现：detail 接口先返回、storeList 后返回时，所属店铺显示空白（6 轮中 2 轮空白，强制延迟 storeList 必现）；storeList 先返回时正常。对应 Bug：活动兑奖-编辑活动所属店铺首次进入空白。

### TC_活动兑奖回归_002（P1）编辑待审核活动首次进入所属店铺回显校验

  2. 核对所属店铺字段回显。
  3. 返回列表再次进入编辑，核对显示一致性。
  4. 抓取 detail 与 storeList 接口返回顺序。
- **预期结果**
  1. 首次进入所属店铺正常回显（如 抖音/华硕官方旗舰店）。
  2. detail 返回 storeId/platformId 正确。
  3. detail 先于 storeList 返回时同样正常回显，不出现空白。
- **本次实测状态**：疑似缺陷。2026-08-12：自然 4 轮均正常（storeList 先返回）；强制延迟 storeList（detail 先返回）后所属店铺空白，与 007 同一竞态根因。

### TC_活动兑奖回归_004（P2）编辑活动邮件截图回显校验
- **前置**：存在含邮件截图的不同审核状态活动（通过 147/146、待审核 139、未通过 118）。

- **预期结果**
  1. 编辑页邮件截图缩略图正常显示，无裂图/空白/异常占位。
  2. detail 返回的 mailImg URL 可访问（HTTP 200）且为图片。
  3. 多条截图（逗号分隔）逐张显示，上限 9 张。
- **本次实测状态**：疑似缺陷。2026-08-12：活动 146/147 的 mailImg 为双编码路径（%2Fdev%2Ffile…），访问返回 404，编辑页缩略图加载失败不显示；139/118/132/119 正常（200）。与审核状态无关，为存量数据/上传存储问题。
